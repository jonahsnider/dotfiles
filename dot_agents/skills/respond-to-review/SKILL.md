---
name: respond-to-review
description: Guidance on responding to review comments on a pull request or code review.
---

1. Fetch the latest review comments on the relevant changeset
2. Critically analyze the comments posted, especially if they're from automated review tools
   - Are the issues being raised actual concerns? Are they being excessively defensive, based on incorrect assumptions, etc.
3. Implement necessary fixes locally without committing/pushing anything
4. Finalize work
   - Provide a summary of what the review comments were about
   - What the fixes were, or why the comment didn't need to be addressed
   - If relevant, a 1-3 sentence draft of a reply to the reviewer
